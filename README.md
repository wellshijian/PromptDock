# PromptDock 提示词悬浮卡

一个常驻桌面的悬浮小工具，用来存放你常用的提示词（prompt），支持一键复制、搜索、增删改、窗口置顶、最小化到系统托盘。

以下步骤全部在**你自己的 Windows 电脑**上操作。你不需要看懂代码，跟着抄命令即可。

---

## 第一步：安装 Python（如果电脑上还没装）

1. 打开 <https://www.python.org/downloads/>，下载最新的 Python 安装包
2. 运行安装包时，**一定要勾选下面的 "Add python.exe to PATH"**，再点 Install Now
3. 安装完成后，打开电脑的「命令提示符」（按 `Win`，输入 `cmd`，回车），输入：
   ```
   python --version
   ```
   能看到类似 `Python 3.12.x` 就说明装好了。

## 第二步：把这三个文件放到同一个文件夹

- `prompt_dock.py`
- `requirements.txt`
- `README.md`（也就是本文件）

比如放到 `D:\PromptDock\` 这个文件夹里。

## 第三步：安装依赖

在命令提示符里，先进入这个文件夹（把路径换成你自己的）：

```
cd D:\PromptDock
```

然后安装依赖：

```
pip install -r requirements.txt
```

等它跑完（第一次会下载一些文件，稍等一会）。

## 第四步：先直接运行试试看

```
python prompt_dock.py
```

如果一切正常，桌面上会弹出一个悬浮小窗口，里面有 3 条示例提示词（一开始就是纯平铺列表，不会自动出现任何"未分类"之类的分组标题——只有当你置顶了某条，或者自己建了文件夹，才会出现对应的分组）。可以先试试：

- **点击**卡片（或多段提示词里的某一段）= 复制那一段内容，会短暂显示"✅ 已复制"文字提示，不会弹窗打断你
- **直接按住卡片拖动**（除了点击复制以外的正常拖动手势）可以把卡片挪到新位置，拖到别的文件夹分组下面会自动改分类
- 列表里的分组标题（比如"工作 (2)"）点一下箭头可以**折叠/展开**（现在改成松开时判断有没有明显移动，避免手滑碰到就意外展开/收起）；"置顶"分组永远显示在最上面，不会被折叠；新建的文件夹会排在其他文件夹前面（最近建的排最上）
- **右键点击**文件夹分组标题 = 弹出「重命名文件夹 / 删除文件夹」菜单（删除只是把里面的提示词挪回"未分类"，不会连带删掉提示词内容；"置顶"和"未分类"这两个特殊分组没有这个菜单）
- **右键点击**卡片 = 弹出「编辑 / 删除 / 置顶 / 卡片颜色 / 移动到文件夹」菜单
- **右键点击**列表空白处 = 弹出「＋ 添加新提示词 / ＋ 新建文件夹」菜单
- 新增/编辑提示词的弹窗里可以点「＋ 添加一段提示词」，一条提示词能放好几段内容，各自独立复制，自动编号；这个弹窗里**不需要选文件夹**，新建的提示词一律先进"未分类"，想分类的话之后在卡片上右键"移动到文件夹"
- 标题栏空白处（不是搜索框、不是右边三个图标的地方）按住可以**拖动**整个窗口
- 右上角三个图标：📌 置顶开关（窗口级）/ — 最小化到托盘 / ✕ 关闭（隐藏到托盘，不会真正退出）
- **系统托盘图标右键**：
  - 「导出」/「导入」→ 备份或批量导入提示词（格式见下面）
  - 「打开数据文件夹」→ 直接打开存放数据的文件夹，方便你自己手动备份
  - 「外观设置...」→ 窗口透明度 + 主题配色
  - 「设置快捷键...」→ 两个全局快捷键：默认 `Shift+Z` 呼出/隐藏悬浮窗，`Shift+X` 打开全屏草稿纸
  - 「开机自动启动」→ 勾选后开机自动运行，不用每次手动打开
- 界面最下方是拉宽字距的"WELLSHIJIAN"署名

### 草稿纸（隐藏功能，界面上没有常驻入口）

按 `Shift+X`（可在"设置快捷键"里改）会在**同一个悬浮窗里**切换到"草稿纸"页面（窗口大小不变，不会占用整个屏幕），跟卡片列表共用同一个标题栏：
- 工具栏：**B**（加粗）/ **A-**（缩小）/ **A+**（放大）/ **标题**（选中内容变成大号加粗）
- `Ctrl+F` 呼出查找，`Ctrl+H` 呼出查找替换（支持替换一个 / 全部替换），再按输入框旁边的 `×` 关闭
- 以上按钮选中文字后点击生效；不选中就是从光标位置开始应用
- 右下角实时显示字数
- 下面一大块文本框，随便写随便改
- 停止输入 0.5 秒后自动保存到本地（连同格式一起保存），不用手动点保存，下次打开还在
- 「清空」直接清空草稿（不会弹确认框）；「复制」把当前内容（纯文本，不含格式）复制到剪贴板
- 按 `Esc` 退出草稿纸，回到卡片列表；或者再按一次 `Shift+X` 也能退出（跟进去用的是同一个快捷键，双向切换）

草稿纸内容单独存了一个文件：`...\AppData\Roaming\PromptDock\draft.html`（保存的是带格式的 HTML，不是纯文本）

⚠️ **提醒**：`Shift+Z` / `Shift+X` 这种只用 Shift 当修饰键的组合，理论上你在**任何软件**里打字打出大写 Z 或 X（按住 Shift 敲这两个键）都会触发这两个快捷键，可能被日常打字误触发。如果用起来发现经常被误触发，去"设置快捷键"里换成 `Ctrl+Alt+`开头这种更少见的组合就行。

如果这一步能正常跑起来，说明代码没问题，可以进行下一步打包。

### 数据存放在哪里？丢了怎么办？

所有提示词和设置都存在这两个文件里（跟 exe 放在哪个文件夹无关，换个位置运行也不会丢）：

```
C:\Users\你的用户名\AppData\Roaming\PromptDock\prompts.json    ← 所有提示词
C:\Users\你的用户名\AppData\Roaming\PromptDock\settings.json   ← 快捷键/主题/文件夹等设置
```

在托盘图标右键点「打开数据文件夹」就能直接跳转过去，建议偶尔用「导出」功能备份一份 txt 到别的地方（比如网盘），这样即使系统重装、文件损坏，也能用「导入」功能整体恢复。

### 关于拖拽的一个提醒

这次把"点击卡片复制"这个交互加上了，和"拖拽卡片排序"用的是同一块区域，我在代码里加了个判断（点击时鼠标几乎没有移动才算"复制"，移动幅度大就当作"拖拽"，不会触发复制），逻辑测试是通过的。但真实拖拽手感这种东西我这边环境测不出来，麻烦你重点感受一下拖拽和点击复制会不会互相干扰，有问题告诉我。

### 关于 txt 导入导出的文件格式

导出出来的文件长这样，你也可以自己手写一个同样格式的 txt 文件，然后用「导入」功能批量导入：

```
标题: 写作开场白
文件夹: 默认
内容:
请用简洁有力的语言帮我写一段开场白，主题是：
===
标题: 文案套装
文件夹: 工作
内容:
[开头]
请帮我写一段吸引人的开头
[结尾]
请帮我写一段总结性的结尾
===
```

规则：
- 每一条提示词是一个「标题:」+「文件夹:」+「内容:」的小段落
- 每条之间用单独一行的 `===` 隔开
- 只有一段内容的话，「内容:」下面直接写正文
- 有多段内容的话，每段前面加一行 `[小标题]`（小标题随便写，比如 `[开头]`），后面跟这一段的正文
- 导入的时候是**追加**到现有列表后面，不会覆盖或删除你已有的提示词，用到的文件夹如果不存在会自动创建

如果这一步能正常跑起来，说明代码没问题，可以进行下一步打包。

## 第五步：打包成 .exe

安装打包工具：

```
pip install pyinstaller
```

然后执行打包命令：

```
pyinstaller --noconsole --onefile --name PromptDock prompt_dock.py
```

- `--noconsole`：运行时不弹黑色命令行窗口
- `--onefile`：打包成单个 exe 文件，方便分发
- `--name PromptDock`：给生成的 exe 起名字

打包过程可能需要 1~3 分钟。完成后，打开当前文件夹下新出现的 `dist` 文件夹，里面的 **`PromptDock.exe`** 就是最终成品，双击即可运行，可以随意拷贝到桌面或者设置开机启动。

## 常见问题

**Q: 双击 exe 没反应 / 一闪而过？**
先用命令行方式运行看报错：在 `dist` 文件夹里打开命令提示符，输入 `PromptDock.exe`，看看提示什么错误，把错误信息发给我，我帮你看。

**Q: 数据（我添加的提示词）保存在哪里？会不会丢？**
保存在 `C:\Users\你的用户名\AppData\Roaming\PromptDock\prompts.json`，是个文本文件，换电脑的话把这个文件拷过去就行，卸载重装 exe 也不会丢数据。

**Q: 想让它开机自动启动？**
把 `PromptDock.exe` 的快捷方式放进：
`C:\Users\你的用户名\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup`
下次开机就会自动弹出来。

**Q: 想改颜色/圆角/大小？**
打开 `prompt_dock.py`，找到最上面的 `STYLE = """ ... """` 这一段，里面每个色值和数字都有注释可以直接改，改完重新跑一遍第五步打包命令即可。

**Q: 想换 logo 图标？**
现在的 logo 只用在「系统托盘图标」和「exe 文件本身的图标」上，悬浮卡片界面里不显示。这张图已经内嵌在代码里了（`LOGO_PNG_BASE64` 那一长串字符），不需要额外带图片文件。如果以后想换别的图片，把新图片发给我，我帮你重新生成这段代码。

**Q: 想让 .exe 文件本身在文件夹里显示这个 logo（不只是运行起来之后）？**
这个需要一个 `.ico` 格式的图标文件，打包时加一个参数：
```
pyinstaller --noconsole --onefile --name PromptDock --icon=icon.ico prompt_dock.py
```
如果需要，把图片发我，我可以帮你转换成 `.ico` 格式。
